# IIPMPayroll

## Local startup

The backend requires Java 17 or newer and uses the existing JAR at
`target/iipm-payroll-system-0.0.1-SNAPSHOT.jar`.

From PowerShell, run:

```powershell
.\start-backend.ps1
```

The script checks Java, prevents duplicate backend processes, starts the JAR on
port `3330`, and writes startup output to `backend.log` and `backend-error.log`.
The frontend runs separately from `frontend` with `npm start` and is available
at `http://localhost:2220`.
